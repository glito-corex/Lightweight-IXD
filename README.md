# Internet Xtreme Downloader (IXD)

IXD is a fork of **Arminmacx's original project**.

This fork focuses on streamlining the original codebase by removing unnecessary components, reducing overhead and keeping the features that matter.

The goal is to maintain the core downloading capabilities while making the project lighter, cleaner and more focused.

## Main Features

- Multi-connection downloads
- Dynamic chunk allocation
- Pause, resume and cancel support
- YouTube and Twitch extraction
- HLS and MPEG-DASH support
- Audio/video merging (MP4 and WebM)
- Automatic retries and recovery
- Bandwidth management
- HTTP, HTTPS and SOCKS5 proxy support
- File integrity verification
- Download scheduling
- Browser integration
- SQLite-based download history

## Project Direction

Unlike the original project, this fork prioritizes:

- Removing unnecessary components.
- Reducing application overhead.
- Simplifying the codebase.
- Keeping essential downloading functionality.
- Maintaining an independent and efficient download engine.

**Original project:** Arminmacx

This project is independently modified and maintained as a lightweight fork.
